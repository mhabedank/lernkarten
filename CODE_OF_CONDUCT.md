# Code of Conduct

## The short version

Be decent to each other. This is a small project about printing flashcards —
nobody needs to have a bad day over it.

## What we expect

- Assume good faith, and give feedback on the change, not on the person.
- Welcome beginners. "I don't know how this works" is a fine thing to say.
- Respect that maintainers and contributors do this in their spare time. A
  pull request or an issue may sit for a while; a reminder is fine, pressure
  is not.

## What is not acceptable

Harassment, insults, or discriminatory remarks — including about age,
disability, ethnicity, gender identity, appearance, nationality, religion or
sexual orientation. Publishing someone's private information without their
consent. Deliberately derailing discussions.

This applies everywhere the project happens: issues, pull requests, commit
messages, code review, and any other project space.

## Reporting

If you experience or witness a problem, contact the maintainer directly on
GitHub ([@mhabedank](https://github.com/mhabedank)) rather than opening a
public issue. Reports are handled confidentially.

Maintainers may edit or delete comments, close issues and pull requests, or
block accounts when this document is violated, and will explain the decision
where it is reasonable to do so.

## Attribution

Written in the spirit of the [Contributor
Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
kept short on purpose.
