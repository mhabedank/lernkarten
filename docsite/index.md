# lernkarten

Turn what you have to learn into flashcards you can hold.

This is the documentation. The [landing page](../docs/index.html) says what the
project is and shows what the cards look like; these pages say how to run it
and how to work on it.

The site has two areas. **Using lernkarten** is for someone who wants a deck of
cards out of their own material. **Contributing** is for someone changing the
tool itself — what the card layout means, how the project is tested, and what
has to be green before a pull request.
